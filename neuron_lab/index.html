What the simulation is doing

1. Input event

An excitatory event raises AMPA conductance; an inhibitory event raises GABA conductance.

2. Voltage update

Conductances pull voltage toward 0 mV (excitation) or −80 mV (inhibition), while leak pulls it to rest.

3. Spike decision

At threshold, the neuron emits one spike, resets, and cannot spike during its refractory period.
